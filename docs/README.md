# How to read the docs
You can read full documentation in markdown format inside `md` folder, but you'll will have broken links.
If you want nice visual and styled HTML, you can clone this repo and open
`html/index.html`. From there you can easily jump between chapters.

> [!NOTE]
> Markdown files are up to date with latest commits.
> Parsed documentation should be based on latest release.
> This means you may see new things in markdown, which aren't
> in the latest release tag.
