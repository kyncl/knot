# Internal Modes

These modes are not required for the day-to-day use of
Knot. They handle internal backend communication with
remote servers via SSH.

Unless you are contributing to Knot's development or
debugging its network protocols, you can safely skip
this chapter.

## Overview

This chapter covers the following internal commands:

* **[Crawl](crawl.html)**
* **[File System](file-system.html)**
* **[Local Archive](local-archive.html)**
